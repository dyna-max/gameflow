Merge into the EXISTING Vite configuration; do not replace its plugins or other settings:
server: {
  proxy: {
    // Matches /gf and /gf/... only, so a game route like /gfx stays with the game.
    '^/gf(/|$)': {
      target: 'http://127.0.0.1:8002',
      changeOrigin: true,
      // Keeps Catalog local even when the game's dev script uses --host. Returning false gives a 404.
      bypass: req => (['127.0.0.1', '::1', '::ffff:127.0.0.1'].includes(req.socket.remoteAddress) ? undefined : false)
    }
  }
}
Start Catalog separately with PORT=8002 npm start from its folder.
Visit the GAME dev server URL + /gf. Preserve /gf in the proxy path.
Use a free port; 8002 is an example, not a requirement.
